KVM常用操作整理

本文整理 KVM 虚拟化日常运维中最常用的操作,包括桥接网络配置、虚拟机的创建与导入、磁盘格式转换、克隆、迁移、磁盘扩容等,方便随时查阅。 一、网络桥接配置 桥接后,虚拟机可以像物理机一样直接获得局域网 IP。下面有两种配置方法。 方法 1:修改网卡配置文件 修改完成后直接重启系统,不要只重启网卡。 配置文件位于 /etc/sysconfig/network-scripts/ 目录下(CentOS / RHEL 系)。 创建桥接网卡配置 ifcfg-br0: vim ifcfg-br0 DEVICE="br0" ONBOOT="yes" TYPE="Bridge" BOOTPROTO="none" IPADDR="192.168.19.196" GATEWAY="192.168.19.1" STP="on" DELAY="0" DNS1=192.168.19.1 DNS2=202.96.128.86 修改物理网卡配置 ifcfg-enp6s0,让它加入网桥: vim ifcfg-enp6s0 DEVICE=enp6s0 ONBOOT=yes BRIDGE="br0" 注意:物理网卡名称(这里是 enp6s0)和 IP、网关、DNS 都要按实际环境替换。 方法 2:命令行操作 执行后网络会中断,重启系统后恢复正常。 # 创建网桥 virsh iface-bridge eth0 br0 # 删除 virbr0 虚拟交换机(默认 NAT 网络) virsh net-destroy default virsh net-undefine default 问题:虚拟机可以 ping 通 IP,但无法 ping 通域名 这通常是网桥的流量被宿主机的 iptables / 防火墙规则过滤导致的。在宿主机上关闭桥接流量过滤。 ...
