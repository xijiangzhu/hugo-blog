Nginx常用配置与Rewrite规则整理

本文整理 Nginx 日常配置中最常用的内容:正则匹配符、文件判断、rewrite 指令与 flag、常见规则实例、全局变量,以及与 Apache 规则的对应关系。 一、正则表达式匹配 符号 含义 ~ 区分大小写匹配 ~* 不区分大小写匹配 !~ 区分大小写不匹配 !~* 不区分大小写不匹配 二、文件及目录匹配 符号 含义 -f / !-f 判断文件是否存在 / 不存在 -d / !-d 判断目录是否存在 / 不存在 -e / !-e 判断文件或目录是否存在 / 不存在 -x / !-x 判断文件是否可执行 / 不可执行 三、rewrite 指令的 flag 标记 rewrite 指令的最后一个参数是 flag 标记,常用的有四种: flag 说明 last 相当于 Apache 里的 [L] 标记,表示本条规则执行完后,用重写后的 URI 重新发起请求(重新匹配 server{} 中的 location) break 本条规则匹配完成后,终止匹配,不再匹配后面的规则 redirect 返回 302 临时重定向,浏览器地址栏会显示跳转后的 URL permanent 返回 301 永久重定向,浏览器地址栏会显示跳转后的 URL 使用 last 和 break 实现 URI 重写时,浏览器地址栏不变,但两者有细微差别: 使用 alias 指令时,必须用 last 标记。 使用 proxy_pass 指令时,需要用 break 标记。 last 在本条 rewrite 规则执行完毕后,会对其所在的 server{...} 重新发起请求;break 则在本条规则匹配完成后直接终止匹配。 ...
