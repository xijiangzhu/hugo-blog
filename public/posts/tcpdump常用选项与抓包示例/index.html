Tcpdump常用选项与抓包示例

tcpdump 是 Linux 下常用的命令行抓包工具,可以按条件捕获网络接口上的数据包,用于排查网络问题和分析协议。本文整理它的常用选项,并给出抓取 MySQL 和 HTTP 数据包的实例。

一、tcpdump 选项介绍#

输出显示相关#

选项 说明
-A 以 ASCII 码方式显示每个数据包(不显示链路层头部信息),抓取包含网页数据的包时很有用
-X 同时以 16 进制和 ASCII 形式显示协议头和包内容,做协议分析时非常有用
-e 在输出行打印数据链路层的头部信息,包括源 MAC、目的 MAC 以及网络层协议
-v 输出稍微详细的信息,例如 IP 包中的 TTL 和服务类型
-vv 输出更详细的报文信息
-t 在每一行输出中不打印时间戳
-l 使标准输出变为行缓冲形式

地址与名称解析相关#

选项 说明
-a 将网络地址和广播地址转换成名字
-n 不进行域名解析,直接显示 IP 地址
-nn 不解析主机名,也不把端口号转换成应用(服务)名称,直接显示 IP 和端口号
-f 将外部的 Internet 地址以数字形式打印出来

抓包控制相关#

选项 说明
-i 指定监听的网络接口
-c 收到指定数目的包后,tcpdump 就会停止
-s snaplen 从每个包中截取的字节数。0 表示不截断,抓取完整的数据包。老版本默认只抓 68 字节,新版本默认已能抓取完整的包
-p 不将网卡设置为混杂模式,只抓取与本机相关的数据包
-T 将监听到的包直接解释为指定类型的报文,常见类型有 rpc(远程过程调用)和 snmp(简单网络管理协议)

文件读写相关#

选项 说明
-w 直接将包写入文件,不分析也不打印
-r 从指定文件中读取包(这些包一般通过 -w 选项产生)
-F 从指定文件中读取过滤表达式,忽略命令行中的其他表达式

匹配代码输出相关#

选项 说明
-d 将匹配信息包的代码以人们能够理解的汇编格式输出
-dd 将匹配信息包的代码以 C 语言程序段的格式输出
-ddd 将匹配信息包的代码以十进制的形式输出

参考资料:tcpdump 详解

二、常用抓包实例#

1. 抓取本机 MySQL 的包#

tcpdump -i eth0 -nvX dst 10.47.77.168 and port 3306

命令说明:

部分 含义
-i eth0 监听 eth0 网卡
-nvX 等于 -n -v -X:不解析名称、输出详细信息、以 16 进制和 ASCII 显示内容
dst 10.47.77.168 目的地址是 10.47.77.168
and port 3306 并且端口是 3306(MySQL 默认端口)

2. 抓取 HTTP 包#

tcpdump -i eth0 -A -s 0 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12]&0xf0)>>2)) != 0)'

命令说明:

  • -A:以 ASCII 方式显示包内容,方便直接看到 HTTP 请求和响应文本。
  • -s 0:抓取完整的数据包,不截断。
  • tcp port 80:只抓 TCP 80 端口的包。
  • 后面括号里的条件用来过滤掉没有数据的包(如三次握手、纯 ACK 包),只保留真正携带 HTTP 内容的包。它的计算原理是:
IP 总长度            ip[2:2]
- IP 头部长度        (ip[0]&0xf)<<2
- TCP 头部长度       (tcp[12]&0xf0)>>2
= TCP 数据部分的长度,不等于 0 时才显示

整个过滤表达式要用单引号括起来,避免被 shell 解析括号和特殊符号。

三、常用过滤表达式补充#

tcpdump 的过滤表达式可以用 and、or、not 组合:

表达式 说明
host 192.168.1.10 源或目的地址是该主机
src host 192.168.1.10 源地址是该主机
dst host 192.168.1.10 目的地址是该主机
port 80 源或目的端口是 80
portrange 8000-8100 端口在指定范围内
tcp / udp / icmp 只抓指定协议的包
net 192.168.1.0/24 指定网段

常见组合示例:

# 抓取与某主机 80 端口之间的通信
tcpdump -i eth0 -nn host 192.168.1.10 and port 80

# 抓取 ICMP(ping)包
tcpdump -i eth0 -nn icmp

# 抓取 100 个包后退出,并保存到文件
tcpdump -i eth0 -c 100 -w capture.pcap

# 读取保存的抓包文件
tcpdump -nn -r capture.pcap

保存的 .pcap 文件也可以用 Wireshark 打开,方便图形化分析。

四、使用提示#

  1. 需要 root 权限:一般用 sudo tcpdump ... 运行。
  2. 抓取所有网卡:-i any 可以监听所有接口。
  3. 生产环境谨慎使用:抓包会占用 CPU 和磁盘,建议加上 -c 限制数量,或用过滤条件缩小范围,必要时用 -w 写文件而不是直接打印。
  4. HTTPS 看不到明文:加密流量抓到的是密文,只能分析连接和包大小等信息。
