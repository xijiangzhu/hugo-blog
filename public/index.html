tcpdump 是 Linux 下常用的命令行抓包工具,可以按条件捕获网络接口上的数据包,用于排查网络问题和分析协议。本文整理它的常用选项,并给出抓取 MySQL 和 HTTP 数据包的实例。 一、tcpdump 选项介绍 输出显示相关 选项 说明 -A 以 ASCII 码方式显示每个数据包(不显示链路层头部信息),抓取包含网页数据的包时很有用 -X 同时以 16 进制和 ASCII 形式显示协议头和包内容,做协议分析时非常有用 -e 在输出行打印数据链路层的头部信息,包括源 MAC、目的 MAC 以及网络层协议 -v 输出稍微详细的信息,例如 IP 包中的 TTL 和服务类型 -vv 输出更详细的报文信息 -t 在每一行输出中不打印时间戳 -l 使标准输出变为行缓冲形式 地址与名称解析相关 选项 说明 -a 将网络地址和广播地址转换成名字 -n 不进行域名解析,直接显示 IP 地址 -nn 不解析主机名,也不把端口号转换成应用(服务)名称,直接显示 IP 和端口号 -f 将外部的 Internet 地址以数字形式打印出来 抓包控制相关 选项 说明 -i 指定监听的网络接口 -c 收到指定数目的包后,tcpdump 就会停止 -s snaplen 从每个包中截取的字节数。0 表示不截断,抓取完整的数据包。老版本默认只抓 68 字节,新版本默认已能抓取完整的包 -p 不将网卡设置为混杂模式,只抓取与本机相关的数据包 -T 将监听到的包直接解释为指定类型的报文,常见类型有 rpc(远程过程调用)和 snmp(简单网络管理协议) 文件读写相关 选项 说明 -w 直接将包写入文件,不分析也不打印 -r 从指定文件中读取包(这些包一般通过 -w 选项产生) -F 从指定文件中读取过滤表达式,忽略命令行中的其他表达式 匹配代码输出相关 选项 说明 -d 将匹配信息包的代码以人们能够理解的汇编格式输出 -dd 将匹配信息包的代码以 C 语言程序段的格式输出 -ddd 将匹配信息包的代码以十进制的形式输出 参考资料:tcpdump 详解 ...
