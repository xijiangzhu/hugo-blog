Hexo安装和使用

Hexo 是一个基于 Node.js 的快速、简洁的静态博客框架,支持 Markdown 写作,可以一键部署到 GitHub Pages、Vercel 等平台。本文介绍 Hexo 的安装流程、NexT 主题的安装与配置,以及日常使用的常用命令。 一、环境准备 Hexo 依赖 Node.js 和 Git,请先安装。 1. 安装 Node.js 前往 Node.js 官网 下载 LTS(长期支持)版本并安装。 2. 安装 Git 前往 Git 官网 下载安装,macOS 与 Linux 通常已自带。 3. 验证安装 node -v npm -v git --version 三条命令都能输出版本号,说明环境就绪。 国内网络下 npm 下载较慢,可以切换镜像: npm config set registry https://registry.npmmirror.com 二、安装 Hexo 1. 全局安装 hexo-cli npm install -g hexo-cli 验证: hexo -v 2. 初始化博客 hexo init myblog cd myblog npm install myblog 是博客目录名,可以自定义。 初始化完成后,目录结构如下: myblog/ ├── _config.yml # 站点配置文件 ├── package.json # 依赖信息 ├── scaffolds/ # 文章模板 ├── source/ # 资源文件夹 │ ├── _drafts/ # 草稿 │ └── _posts/ # 文章 └── themes/ # 主题文件夹 3. 本地预览 hexo server 浏览器访问 http://localhost:4000,看到默认页面即安装成功。按 Ctrl + C 停止服务。 ...
