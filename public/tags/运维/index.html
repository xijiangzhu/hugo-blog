Kubectl常用命令整理

本文整理 kubectl 日常使用中最常用的命令,按功能分类:查看资源、删除资源、查看日志、创建与更新、伸缩、调试、节点维护和应用更新回滚,方便随时查阅。 零、常用选项 选项 说明 -n <命名空间> 指定命名空间,不写则使用当前默认命名空间 --all-namespaces / -A 所有命名空间 -o wide / -o yaml / -o json 指定输出格式 -l <标签> 按标签筛选资源 -f <文件> 指定 YAML / JSON 文件 一、get(查看资源) # get 命令的基本输出 kubectl get services # 列出当前命名空间下的所有 services kubectl get pods --all-namespaces # 列出所有命名空间下的全部 Pods kubectl get pods -o wide # 列出当前命名空间下的全部 Pods,并显示更详细的信息 kubectl get deployment my-dep # 列出某个特定的 Deployment kubectl get pods # 列出当前命名空间下的全部 Pods kubectl get pod my-pod -o yaml # 获取一个 Pod 的 YAML kubectl get node -o wide # 列出所有节点,并显示详细信息 # 显示所有 Pods 的标签(或任何其他支持标签的 Kubernetes 对象) kubectl get pods --show-labels # 列出当前命名空间下所有 Services,按名称排序 kubectl get services --sort-by=.metadata.name 二、delete(删除资源) # 删除在 pod.json 中指定的类型和名称的 Pod kubectl delete -f ./pod.json # 删除名称为 "baz" 和 "foo" 的 Pod 和服务 kubectl delete pod,service baz foo # 删除包含 name=myLabel 标签的 Pods 和服务 kubectl delete pods,services -l name=myLabel # 删除在 mynamespace 命名空间中全部的 Pods 和服务 kubectl delete pod,svc --all -n mynamespace # 删除所有与 pattern1 或 pattern2 awk 模式匹配的 Pods kubectl get pods -n mynamespace --no-headers=true | awk '/pattern1|pattern2/{print $1}' | xargs kubectl delete -n mynamespace pod 删除操作不可恢复,尤其是带 --all 的命令,执行前请确认命名空间和范围。 ...
