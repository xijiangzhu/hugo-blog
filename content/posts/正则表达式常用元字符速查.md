正则表达式中的**元字符**(又叫字符集),就是用一些特殊符号来表示特定种类的字符或位置。下面列出常用元字符及其含义,这些通用元字符在不同语言中的作用基本相同。

<!-- more -->

## 一、常用元字符速查

### 1. 匹配字符内容

| 符号 | 代表意思 | 使用场景 |
| --- | --- | --- |
| `\d` | 数字 0-9 | `\d` 匹配单个数字:1、2、3 |
| `\D` | 非数字 | `\D` 匹配单个非数字:a、-、' |
| `\w` | 字母、数字、下划线 | `\w` 匹配单个字母、数字、下划线:a、1、_ |
| `\W` | 非字母、数字、下划线 | `\W` 匹配单个非字母、数字、下划线:{、-、[ |
| `\s` | 空白字符 | `\s` 匹配单个空格、换行(`\n`)、制表符(`\t`) |
| `\S` | 非空白字符 | `\S` 匹配单个非空格、非换行、非制表符的字符 |
| `.` | 除换行符之外的所有字符 | `.` 匹配单个换行符以外的任意字符 |

### 2. 匹配次数

| 符号 | 代表意思 | 使用场景 |
| --- | --- | --- |
| `*` | 0 次及 0 次以上 | `\d*` 匹配数字:123、02、空 |
| `+` | 1 次及 1 次以上 | `\d+` 匹配数字:123、02、3 |
| `?` | 0 次或 1 次 | `\d?` 匹配数字:2、空 |
| `{m,n}` | m 次到 n 次 | `\d{1,3}` 匹配数字:2、12、123 |
| `{n}` | 恰好 n 次 | `\d{2}` 匹配数字:12 |
| `{n,}` | n 次及 n 次以上 | `\d{2,}` 匹配数字:12、123、1234 |

### 3. 匹配位置

| 符号 | 代表意思 | 使用场景 |
| --- | --- | --- |
| `^` | 字符串开始位置 | `^abc` 中的 `^` 匹配字符串开头,即 a 前面的位置 |
| `$` | 字符串结束位置 | `abc$` 中的 `$` 匹配字符串结尾,即 c 后面的位置 |
| `\b` | 单词(`\w`)与非单词之间的位置 | `a\b=` 匹配 "a" 与 "=" 之间的位置 |
| `\B` | 非单词边界的位置 | `a\Bb` 匹配 "a" 与 "b" 之间的位置 |

### 4. 其他元字符

| 符号 | 代表意思 | 使用场景 |
| --- | --- | --- |
| `[]` | 匹配范围 | `[a-zA-Z]` 匹配单个英文字母 |
| `^` | 放在 `[]` 内的开头时,表示取反(放在最前面时才是匹配字符串开头) | `[^a-d]` 匹配 a、b、c、d 之外的任意单个字符 |
| `\` | 转义 | `1\+` 匹配 "1+" |
| `\|` | 分支条件(或) | `ab\|cd` 匹配 ab 或 cd |

## 二、详细说明

### 1. 匹配字符

- `.`:匹配除换行符以外的任意字符
- `\w`:匹配字母、数字、下划线或汉字
- `\s`:匹配任意的空白符
- `\d`:匹配数字

### 2. 匹配位置

- `\b`:匹配单词的开始或结束
- `^`:匹配字符串的开始
- `$`:匹配字符串的结束
- `\G`:上一个匹配的结尾(本次匹配开始)
- `\A`:字符串开头(类似 `^`,但不受多行选项的影响)
- `\Z`:字符串结尾或行尾(不受多行选项的影响)
- `\z`:字符串结尾(类似 `$`,但不受多行选项的影响)

### 3. 重复

- `*`:重复零次或更多次
- `+`:重复一次或更多次
- `?`:重复零次或一次
- `{n}`:重复 n 次
- `{n,}`:重复 n 次或更多次
- `{n,m}`:重复 n 到 m 次

### 4. 字符转义

如果想匹配元字符本身,或者正则中的特殊字符,需要使用 `\` 转义。例如:

- 匹配 `*` 这个字符,使用 `\*`
- 匹配 `\` 这个字符,使用 `\\`

需要转义的字符:

```text
$  (  )  *  +  .  [  ]  ?  \  ^  {  }  |
```

### 5. 字符类

当需要匹配明确的字符或字符集合时,就用到字符类。

**特殊字符:**

- `\0hh`:8 进制值 hh 所表示的字符
- `\xhh`:16 进制值 hh 所表示的字符
- `\uhhhh`:16 进制值 hhhh 所表示的 Unicode 字符
- `\t`:制表符(Tab)
- `\n`:换行符
- `\r`:回车符
- `\f`:换页符
- `\e`:Escape
- `\cN`:ASCII 控制字符,例如 `\cC` 代表 Ctrl+C
- `\p{name}`:Unicode 中命名为 name 的字符类,例如 `\p{IsGreek}`

**枚举:**

- `[aeiou]`:匹配一个元音字母
- `[.?!]`:匹配给定的其中一个标点

**范围:**

- `[0-9]`:匹配 0~9 的数字,同 `\d`
- `[a-z]`:匹配所有小写字母
- `[a-zA-Z]`:匹配所有字母
- `[a-z0-9A-Z_]`:等同于 `\w`

### 6. 反义

反义表示匹配**不属于**某个元字符或字符类的字符。

**反义元字符:**

- `\W`:匹配任意不是字母、数字、下划线、汉字的字符
- `\S`:匹配任意不是空白符的字符
- `\D`:匹配任意非数字的字符
- `\B`:匹配不是单词开头或结尾的位置

**反义字符类:**

- `[^x]`:匹配除了 x 以外的任意字符
- `[^aeiou]`:匹配除了 a、e、i、o、u 这几个字母以外的任意字符

### 7. 分支条件

分支条件又叫逻辑运算符,下面的 X 和 Y 表示两个**表达式**:

- `XY`:X 紧跟 Y
- `X|Y`:X 或 Y。从左到右匹配,**满足第一个条件就不会继续匹配后面的分支**

### 8. 分组

下面的表达式统一以 `\w` 为例:

| 写法 | 说明 |
| --- | --- |
| `(\w)` | 被括号包围起来,是一个整体,表示一个分组 |
| `(\w)(\w)` | 自动编号分组:第一个括号是分组 1,第二个括号是分组 2 |
| `(?'Word'\w+)` | 定义了一个名为 Word 的分组 |
| `(?<Word>\w+)` | 同上,另一种写法,定义了一个名为 Word 的分组 |
| `(?:\w+)` | 非捕获分组:匹配表达式,但不捕获匹配的文本,也不分配组号 |

### 9. 反向引用

后面的表达式可以引用前面的某个分组。用 `\1` 表示,就好像把分组 1 匹配到的值赋给了变量 `\1`,这个变量可以在后面任意位置引用。

- `\1`:表示分组 1 匹配的文本
- `\k<Word>`:表示名为 Word 的分组匹配的文本

例如,匹配重复出现的两个英文单词,如 `Hello Hello`、`lei123 lei123`:

```text
(\w+)\s+\1
(?<Word>\w+)\s+\k<Word>
```

## 三、使用提示

1. **不同语言略有差异**:本文的元字符大多是通用的,但 `\A`、`\Z`、`\z`、`\G`、`\e`、`(?'name'...)` 等写法并非所有语言都支持。例如 JavaScript 就不支持 `\A`、`\Z`、`\z`、`\G`。使用前请查阅对应语言的文档。
2. **在代码字符串中要多写一层反斜杠**:例如在 Java 或 Python 的普通字符串里,匹配数字的 `\d` 要写成 `"\\d"`;Python 可以用原始字符串 `r"\d"` 避免。
3. **注意贪婪匹配**:`*`、`+`、`{n,m}` 默认尽可能多地匹配,在后面加 `?`(如 `.*?`)可以变成尽可能少地匹配。
