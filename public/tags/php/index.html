Docker Compose搭建Nginx+PHP+MySQL环境

本文通过一个 demo,使用 Docker Compose 一键编排 Nginx + PHP-FPM + MySQL 三个容器,搭建一套常见的 PHP 运行环境,并验证 PHP 能够连接 MySQL。 版本说明:本文基于较早的版本编写(Compose 1.19.0、PHP 7.2、MySQL 5.7),这些版本都已停止维护。思路和写法仍然适用,实际使用时建议换成较新的镜像版本,文末「使用提示」里有具体说明。 一、镜像选择 1. Nginx nginx 官方镜像使用 latest tag。 2. PHP PHP 版本较多,可以在 PHP 官方镜像中选一个 tag。本文使用 7.2-fpm(作者使用 latest 无法正常启动)。 PHP 的 Dockerfile 要让 PHP 连接 MySQL,需要在 Docker 官方的 PHP 镜像上额外安装 mysqli 扩展,所以用 Dockerfile 构建一个新镜像。 新建 php-mysqli 目录: mkdir php-mysqli cd php-mysqli vi Dockerfile 编辑 Dockerfile,内容如下: FROM php:7.2-fpm RUN apt-get update \ && docker-php-ext-install mysqli FROM php:7.2-fpm:表示基于 php:7.2-fpm 镜像。 RUN 后面的指令:在构建镜像时执行,用来安装扩展。 这里不需要手动 build 镜像,后面使用 docker-compose 时会自动构建。 ...
