正则表达式常用元字符速查

正则表达式中的元字符(又叫字符集),就是用一些特殊符号来表示特定种类的字符或位置。下面列出常用元字符及其含义,这些通用元字符在不同语言中的作用基本相同。 一、常用元字符速查 1. 匹配字符内容 符号 代表意思 使用场景 \d 数字 0-9 \d 匹配单个数字:1、2、3 \D 非数字 \D 匹配单个非数字:a、-、' \w 字母、数字、下划线 \w 匹配单个字母、数字、下划线:a、1、_ \W 非字母、数字、下划线 \W 匹配单个非字母、数字、下划线:{、-、[ \s 空白字符 \s 匹配单个空格、换行(\n)、制表符(\t) \S 非空白字符 \S 匹配单个非空格、非换行、非制表符的字符 . 除换行符之外的所有字符 . 匹配单个换行符以外的任意字符 2. 匹配次数 符号 代表意思 使用场景 * 0 次及 0 次以上 \d* 匹配数字:123、02、空 + 1 次及 1 次以上 \d+ 匹配数字:123、02、3 ? 0 次或 1 次 \d? 匹配数字:2、空 {m,n} m 次到 n 次 \d{1,3} 匹配数字:2、12、123 {n} 恰好 n 次 \d{2} 匹配数字:12 {n,} n 次及 n 次以上 \d{2,} 匹配数字:12、123、1234 3. 匹配位置 符号 代表意思 使用场景 ^ 字符串开始位置 ^abc 中的 ^ 匹配字符串开头,即 a 前面的位置 $ 字符串结束位置 abc$ 中的 $ 匹配字符串结尾,即 c 后面的位置 \b 单词(\w)与非单词之间的位置 a\b= 匹配 “a” 与 “=” 之间的位置 \B 非单词边界的位置 a\Bb 匹配 “a” 与 “b” 之间的位置 4. 其他元字符 符号 代表意思 使用场景 [] 匹配范围 [a-zA-Z] 匹配单个英文字母 ^ 放在 [] 内的开头时,表示取反(放在最前面时才是匹配字符串开头) [^a-d] 匹配 a、b、c、d 之外的任意单个字符 \ 转义 1\+ 匹配 “1+” | 分支条件(或) ab|cd 匹配 ab 或 cd 二、详细说明 1. 匹配字符 .:匹配除换行符以外的任意字符 \w:匹配字母、数字、下划线或汉字 \s:匹配任意的空白符 \d:匹配数字 2. 匹配位置 \b:匹配单词的开始或结束 ^:匹配字符串的开始 $:匹配字符串的结束 \G:上一个匹配的结尾(本次匹配开始) \A:字符串开头(类似 ^,但不受多行选项的影响) \Z:字符串结尾或行尾(不受多行选项的影响) \z:字符串结尾(类似 $,但不受多行选项的影响) 3. 重复 *:重复零次或更多次 +:重复一次或更多次 ?:重复零次或一次 {n}:重复 n 次 {n,}:重复 n 次或更多次 {n,m}:重复 n 到 m 次 4. 字符转义 如果想匹配元字符本身,或者正则中的特殊字符,需要使用 \ 转义。例如: ...
